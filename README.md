# Tana Camps — Elephant

Статическая страница вымышленного сафари-бренда. Обычные HTML, CSS и JavaScript, без фреймворков, npm и сборки.

## Запуск

Откройте `index.html` двойным кликом. Фотографии, текстура и шрифты находятся в `assets/`; интернет для работы не нужен. Меню, поиск, иллюстративная карта и семиминутный визуальный журнал работают локально. Визуальный журнал — беззвучная последовательность предоставленных фотографий, а не видео.

## GitHub Pages

1. Добавьте в репозиторий `index.html`, `styles.css`, `script.js`, `.nojekyll` и папку `assets/` целиком.
2. В GitHub откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Выберите ветку `main` и папку `/ (root)`, затем **Save**.

Все пути относительные: страница подходит и для адреса `username.github.io/repository/`, и для собственного домена. Сборка и секреты не нужны.

Подробности настройки: [официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Режим записи

Откройте `index.html?rec=1` в браузере (добавьте `?rec=1` к адресу открытого файла) или к URL GitHub Pages. После загрузки локальных ресурсов начнётся 6,5-секундный проход:

- 0–1,95 с: hero;
- 1,95–3,35 с: переход к высказыванию;
- 3,35–4,25 с: высказывание;
- 4,25–5,55 с: переход к фактам;
- 5,55–6,5 с: факты.

В режиме записи доступен `window.tanaRecorder`: `seek(3350)` останавливает все анимации на заданной миллисекунде, `play()` продолжает. Для воспроизводимого полного дубля перезагрузите страницу. Рекомендуемый размер кадра: 1440 × 960. На телефоне блок фактов длиннее экрана, поэтому запись показывает его начало; обычная прокрутка позволяет просмотреть весь блок.

## Файлы

- `index.html` — три секции и доступные нативные диалоги.
- `styles.css` — адаптивная сетка, цвета, локальные шрифты, зерно.
- `script.js` — буквенные reveal-анимации, scroll-эффекты, режим записи и взаимодействия.
- `assets/` — предоставленные фотографии и вырезанный слон, SVG-текстура, Bodoni Moda и Inter.

Страница учитывает `prefers-reduced-motion`, поддерживает клавиатуру и остаётся читаемой без JavaScript. Фотографии предоставлены в задании; лицензии шрифтов находятся в `assets/`.
